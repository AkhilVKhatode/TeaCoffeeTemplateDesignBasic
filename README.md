# Beverage Preparation Template Method

This repository implements a template method design pattern to simulate the preparation of beverages such as coffee and tea. The pattern defines the skeleton of the beverage preparation process in the `Beverage` class, and the concrete subclasses (`CoffeeBeverage` and `TeaBeverage`) customize the specific steps like brewing and adding condiments.

## Design Pattern: Template Method

The **Template Method** design pattern defines the basic steps of an algorithm and lets subclasses implement the details of some steps. The algorithm’s structure is defined in a base class, while specific steps are left to the subclasses to implement.

### Steps in the Beverage Preparation Process:
1. **Boiling water**: Common step for all beverages.
2. **Brewing**: Brew the specific beverage (e.g., coffee, tea).
3. **Pouring into the cup**: Common step for all beverages.
4. **Adding condiments**: Specific condiments for each beverage (e.g., milk and sugar for coffee, lemon for tea).
